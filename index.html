01 · Context

Prezentarea aplicației

dm.ro este magazinul online al brandului dm, prin intermediul căruia utilizatorii pot consulta produse, căuta articole, explora categorii și utiliza funcționalitățile de cumpărare disponibile pe site.

Scopul acestui proiect este elaborarea unui set de teste care să verifice comportamentul principalelor funcționalități și să evidențieze aspecte relevante pentru securitatea unei aplicații web.

02 · Organizare

Planul de testare

Obiective

  • Verificarea navigării și a funcțiilor principale ale magazinului.
  • Verificarea afișării și actualizării informațiilor despre produse și coș.
  • Identificarea erorilor de utilizare și a comportamentelor neașteptate.
  • Analiza unor măsuri de securitate observabile în browser.

Domeniul testării

Se testează paginile publice, căutarea, categoriile, filtrele, sortarea și coșul, în măsura în care funcțiile sunt accesibile. Se pot analiza conexiunea HTTPS și antetele de răspuns folosind instrumentele browserului.

Tipuri de testare

  • Funcțională: verifică dacă funcțiile produc rezultatul așteptat.
  • De interfață: verifică afișarea și utilizarea pe desktop și mobil.
  • De regresie: repetă testele după modificări.
  • De securitate neintruzivă: verifică setări și comportamente observabile fără a afecta serviciul.

Criterii de acceptare

Un test este considerat trecut când rezultatul observat corespunde rezultatului așteptat. Dacă diferă, se înregistrează ca eșuat și se atașează dovada: captură, adresă, dată și pași.

Antet Ce se verifică Scop Statut

06 · Securitate

Securitatea API

În cadrul acestui studiu se analizează doar comportamentele API care pot fi observate în mod legitim prin utilizarea normală a site-ului și instrumentele browserului. Nu se efectuează scanări automate sau solicitări neautorizate.

ID Verificare Rezultat așteptat Statut
API-01 Observarea cererilor de rețea generate de paginile publice. Cererile necesare funcției sunt completate fără erori neașteptate. De verificat
API-02 Observarea codurilor HTTP ale cererilor publice. Codurile răspunsurilor corespund rezultatului cererii. De verificat
API-03 Verificarea dacă răspunsurile publice expun date personale sau secrete nejustificate. Răspunsurile nu expun informații sensibile inutile. De verificat
Limită: testele de autorizare, acces la date private și modificarea cererilor API necesită permisiune explicită și un mediu de test.
07 · Securitate

Injecții și validarea datelor

Se verifică în mod sigur validarea intrărilor din funcțiile publice, precum căutarea și formularele disponibile. Se pot folosi valori obișnuite invalide sau caractere speciale nepericuloase, fără a încerca exploatarea sistemului.

ID Scenariu Rezultat așteptat Statut
INJ-01 Introducerea unui termen foarte lung în căutare. Pagina gestionează intrarea fără blocare sau afișare defectuoasă. De verificat
INJ-02 Introducerea de caractere speciale inofensive în căutare. Intrarea este tratată ca text, iar pagina rămâne funcțională. De verificat
INJ-03 Trimiterea unui formular cu câmpuri invalide, dacă există. Aplicația semnalează câmpurile și nu acceptă date invalide. De verificat
INJ-04 Observarea mesajelor de eroare generate de intrări invalide. Mesajele nu divulgă detalii interne tehnice. De verificat

11 · Încheiere

Concluzie

În cadrul acestui studiu individual a fost elaborat un plan de testare pentru magazinul online dm.ro, care include verificarea funcționalităților principale și analiza unor aspecte de securitate ale aplicației web. Scenariile de testare permit evaluarea navigării, căutării produselor, utilizării coșului de cumpărături, autentificării și protecției datelor transmise prin HTTP.

Aplicarea acestor teste contribuie la identificarea eventualelor erori și la înțelegerea importanței securității în dezvoltarea aplicațiilor web. Concluziile finale privind calitatea și securitatea aplicației vor fi formulate în baza rezultatelor obținute efectiv și a dovezilor colectate în timpul testării.
